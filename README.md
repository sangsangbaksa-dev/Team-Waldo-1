# 밤의 파수꾼 · NIGHT WARDEN

TEAM WALDO의 탑다운 3D 서바이벌 게임. WebGL을 사용할 수 없는 브라우저에서는 픽셀 화면으로 플레이할 수 있습니다. 푸른 마력을 다루는 파수꾼이 숲, 폐허, 성역을 지나 밤의 군주와 맞섭니다.

## 플레이

- WASD / 방향키로 이동. 공격은 자동입니다.
- 터치 화면에서는 빈 곳을 누르고 드래그합니다. 휴대폰은 가로 화면을 권장합니다.
- 적이 떨어뜨린 경험치 결정을 모으고, 레벨업 때 카드 또는 1·2·3 키로 능력을 선택합니다.
- ESC / Ⅱ: 일시정지. 소리 버튼: 음소거. 다른 창으로 이동하면 자동으로 일시정지합니다.
- 세 구간을 각각 2분씩 생존한 뒤 마지막 보스를 처치하면 승리합니다. 보스전에는 제한 시간이 없습니다.
- 레벨업 시 체력 6 회복, 중간 보스 처치 시 최대 체력 25% 회복. 체력이 낮으면 회복 카드도 등장합니다.
- 최고 점수와 소리 설정은 브라우저에 저장합니다. 저장소를 사용할 수 없어도 플레이할 수 있습니다.

## 완성된 콘텐츠

직접 제작한 픽셀 캐릭터·8종 적·숲/폐허 아트, 8종 무기(투사체·회전·오라·관통 광선·귀환 초승달·방사형 번개), 6종 유물, 공격 예고와 원거리 보스 패턴, 합성 앰비언트 음악과 효과음, 한국어 안내·성장·일시정지·승리/패배 화면, 키보드/터치 조작.

3D 모델, 지형, 픽셀 아트와 오디오는 코드로 생성하며 외부 이미지/음원에 의존하지 않습니다. 웹폰트는 Google Fonts를 사용하고 오프라인에서는 시스템 폰트로 대체됩니다. 지형은 장식이며 이동을 막지 않습니다.

## 개발 및 검증

Node 22 이상.

```sh
npm ci
npm run dev
npm run typecheck
npm run lint
npm test
npm run validate-data
npm run balance -- --runs 5
npm run build
npm run package-game
```

`dist/`는 정적 웹 배포 폴더입니다. `npm run package-game`은 빌드 결과를 한 파일 `dist/night-warden.html`로 합칩니다. 이 파일은 서버 없이 브라우저로 열어 플레이할 수 있습니다.

`?seed=123`으로 같은 게임을 재현하고 `?speed=10`으로 진행을 가속할 수 있습니다. 개발 모드에만 `window.__game` 검사 핸들이 제공됩니다.

시뮬레이션은 Phaser와 독립된 결정적 30Hz 엔진입니다. 게임 규칙은 `src/sim/`, 아트·연출은 `src/render/`, 화면은 `src/scenes/`, 데이터는 `data/`에서 관리합니다.

## 확인 범위

- RNG, 공간 해시, 진행, 무기, 데이터와 새 전투 패턴 자동 테스트.
- 브라우저에서 이동, 성장 중 시간 정지, 카드 선택, 일시정지/재개, 승리/패배, 재시작을 검증합니다. 보스 및 결과 화면 검증은 개발 상태를 지정한 시나리오입니다.
- 봇 5개 시드가 모두 최종 보스까지 도달하고 1개 시드가 승리했습니다. 사람 플레이에 대한 광범위한 난이도 검증은 아직 하지 않았습니다.
