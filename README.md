# WALDO · Kingdoms at War — Frontiers

**왕국을 키우고, 부대를 지휘하고, 더 넓은 전장을 정복하세요.**

플레이어 1명과 AI 3개 왕국이 경쟁하는 한국어 브라우저 3D 전략 게임입니다. 금광·농장·병영을 운영하고 네 병종을 조합해 거점을 확보합니다. 일반 원정과 **아군 100명 대 적군 500명으로 시작하는 대규모 전쟁**을 세 전장에서 플레이할 수 있습니다.

Three.js 전장과 HTML 관리 화면을 사용합니다. 별도의 게임 서버나 회원가입이 필요하지 않으며, 진행은 현재 브라우저에 저장합니다. 기존 Phaser 클래식 서바이벌은 별도 모드로 유지합니다.

## 시작하기

Node.js **22.13 이상인 22 LTS** 또는 **24 LTS**를 사용합니다. 저장소의 CI는 Node 22를 사용합니다.

```bash
npm ci
npm run dev
```

개발 서버 주소를 열고 **전장 → 난이도 → 새 원정 또는 대규모 전쟁**을 선택하세요. 3D 전장에는 WebGL이 필요합니다. 지원되지 않으면 안내 화면에서 메뉴로 돌아갈 수 있습니다.

첫 플레이에는 **강철 분지 · 입문 · 일반 원정**을 권장합니다. 금광과 농장을 강화하고, 가까운 관문을 확보한 뒤 병영과 연구에 투자해 보세요. `원정` 탭의 원정 계약은 다음 목표를 안내하고 자원 보상을 제공합니다.

## Frontiers 확장

이번 확장은 기존 전투·기지·장군·직접 조작 기능 위에 다음 내용을 추가합니다.

- **세 전장 선택:** 기존 규모의 강철 분지와 면적이 더 넓은 황혼 변경·서리 대륙. 지도 크기, 거점, 본부 위치, 이동과 폭풍 준비 시간이 함께 바뀝니다.
- **바이옴과 작전 지휘소 디자인:** 산업 지대·사막·설원의 조명과 지형 팔레트, 맵별 메뉴 프리뷰, 실제 거점 좌표로 그린 전장 선택 카드, 개선된 전투·기지 UI.
- **전체 작전 지도:** `M` 키로 지도를 열고 부대·목적지를 검토한 다음 출전시킵니다. 위치를 선택하는 동작과 실제 명령을 분리했습니다.
- **원정 계약 9종:** 건설·훈련·점령·연구·장군 모집 등의 실제 진행을 확인해 보상을 받습니다.
- **전술 지원 3종:** 선택한 부대를 즉시 치료하거나 일정 시간 이동·방어 능력을 강화합니다.
- **원정 기록실과 업적 8종:** 최근 20개 완료 전투와 누적 전적, 전장별 승리, 최초 업적 획득 시각을 보관합니다.
- **대규모 전투 계산 개선:** 공간 인덱스를 재사용해 표적 탐색과 거점 점령 계산을 줄입니다. 측정 조건과 한계는 [성능 기록](docs/FRONTIERS_PERFORMANCE.md)에 공개했습니다.
- **v4 저장:** 선택한 맵, 확대 전장의 병력·명령, 계약 보상 수령 상태, 지원 효과·재사용 시간을 보관합니다.

600명으로 시작하는 대규모 전쟁, 5×5 기지 건설, 장군 모집, 세 부대 편성, 낙하산 강하·직접 탐험·성벽 사격은 기존 기능이며 이번 확장에서도 함께 사용할 수 있습니다.

## 전장과 전투 규모

### 세 전장

| 전장 | 월드 크기 | 기본 맵 대비 면적 | 거점 | 일반 원정의 세력당 병력 상한 | 환경 |
| --- | --- | --- | --- | --- | --- |
| 강철 분지 | 520 × 520 | 1배 | 9개 | 18명 | 산업 시설, 교차 전선 |
| 황혼 변경 | 780 × 780 | 2.25배 | 13개 | 30명 | 사막 교역로, 외곽 오아시스 |
| 서리 대륙 | 1040 × 1040 | 4배 | 17개 | 48명 | 설원 개척지, 외곽 보급 기지 |

맵 정보는 [`src/battle/maps.ts`](src/battle/maps.ts)에서 정의합니다. 확대 맵은 빈 땅만 늘리지 않고 본부·거점·시설을 넓게 배치합니다. 황혼 변경은 이동 속도에 1.12배, 서리 대륙은 1.24배 배율을 적용해 긴 진군 거리를 보완합니다. 거점마다 금·식량 생산량이 다릅니다.

### 일반 원정과 대규모 전쟁

| 항목 | 일반 원정 | 대규모 전쟁 |
| --- | --- | --- |
| 시작 병력 | 모든 세력 보병 4명 | 아군 100명, AI 세력별 167·167·166명 |
| 아군 시작 자원 | 금 140 / 식량 100 | 금 8,500 / 식량 7,500 |
| AI 세력별 시작 자원 | 금 140 / 식량 100 | 금 6,500 / 식량 6,000 |
| 시작 시설 | 모든 시설 Lv.1 | 모든 시설 Lv.3 |
| 시작 본부 체력 | 400 | 600 |
| 세력당 병력 상한 | 전장별 18 / 30 / 48명 | 모든 전장 400명 |
| 화면의 일괄 훈련 | 3명 | 25명 |

대규모 전쟁은 수백 명의 병사가 즉시 등장하는 별도 시작 설정입니다. 본부 공성 피해에는 전용 배율이 적용되며, 원정 계약 보상과 전술 지원 비용은 일반 원정의 3배입니다. 실제 프레임 속도는 기기와 그래픽 품질에 따라 달라집니다.

어느 모드든 본부가 함락되면 해당 왕국의 병력과 거점 소유권이 사라집니다. 마지막 생존 왕국이 승리합니다.

## 경제·건설·장군

### 자원과 시설

| 시설 | 기본 효과 | 최대 레벨 |
| --- | --- | --- |
| 금광 | 레벨당 금 +1.5/초 | Lv.4 |
| 농장 | 레벨당 식량 +1.3/초 | Lv.4 |
| 병영 | 병종·연구 해금, 병사 공격력 증가 | Lv.4 |
| 본부 방어 / 방어탑 | 강화 시 최대 체력 +100, 체력 최대 100 회복, 포탑 공격력 증가 | Lv.4 |

금광·농장·병영 강화는 **금 60 × 현재 레벨 / 식량 20 × 현재 레벨**, 본부 방어 강화는 **금 80 × 현재 레벨 / 식량 30 × 현재 레벨**을 사용합니다. 본부의 최대 체력은 Lv.4에서 700입니다.

`K` 또는 기지 관리 버튼에서 **5×5 건설 부지**를 엽니다. 중앙 본부를 제외한 빈 부지를 선택해 금광·농장·병영·방어탑을 배치할 수 있습니다. 관리 패널의 시설 강화와 부지 건설은 같은 시설 레벨·비용을 사용합니다. 이미 차지한 부지나 자원이 부족한 요청은 비용을 차감하지 않습니다.

본부 수리는 **금 45 / 식량 25**로 체력을 최대 100 회복합니다. 체력이 가득 찼다면 자원을 소비하지 않습니다.

| 경제 정책 | 효과 |
| --- | --- |
| 균형 | 기본 생산과 전투 능력 |
| 성장 | 금·식량 생산 +25% |
| 전시 | 병사 공격력 +18%, 금·식량 생산 −12% |

실제 생산량에는 시설·거점 수입, 정책, 보급 연구, 병참 장군과 난이도 배율이 적용됩니다. 상단의 초당 생산량도 같은 계산을 사용합니다.

### 장군

| 장군 | 역할 | 금 / 식량 | 효과 |
| --- | --- | --- | --- |
| 레온 발렌 | 선봉장 | 165 / 90 | 배속 부대 공격력 +18% |
| 소라 하인 | 기동장 | 145 / 105 | 배속 부대 이동 속도 +20% |
| 미라 카엘 | 수호장 | 175 / 115 | 배속 부대의 전투 피해 15% 감소 |
| 한 유진 | 병참총감 | 190 / 130 | 모집 즉시 아군 자원 수입 +12% |

장군은 종류별로 한 번 모집합니다. 전투 장군은 한 부대에 한 명씩 배속하며, 같은 부대에 새 장군을 지정하면 이전 장군은 대기합니다. 병참총감은 부대에 배속하지 않고 왕국 전체에 적용됩니다.

## 병력·부대·연구

| 병종 | 금 / 식량 | 기본 체력 | 역할 | 해금 |
| --- | --- | --- | --- | --- |
| 보병 | 25 / 20 | 52 | 균형 잡힌 근접 병력 | 병영 Lv.1 |
| 궁병 | 45 / 30 | 36 | 원거리 지원 사격 | 병영 Lv.2 |
| 중장병 | 75 / 45 | 125 | 높은 체력으로 전선 유지 | 병영 Lv.3 |
| 기병 | 65 / 55 | 82 | 빠른 이동과 거점 선점 | 병영 Lv.3 |

일괄 훈련은 병력 상한과 필요한 자원을 모두 만족할 때만 실행합니다. 시작 병력은 훈련 통계에 포함하지 않습니다.

병력을 **주력군·기동대·수비대** 세 그룹으로 나누어 별도 명령을 내릴 수 있습니다. 다른 그룹에 편성한 병력은 주력군의 공격 명령을 자동으로 따라가지 않습니다. 전체 복귀 대신 선택 부대만 본부로 보내는 명령도 제공합니다.

관리 화면의 **본부 수비대**는 주력군에서 오래된 병력부터 본부 방어에 남기는 설정입니다. 이름이 같은 세 번째 그룹과는 별개입니다. 적을 발견한 병력은 가까운 위협에 자동 대응한 뒤 지정 목적지로 이동합니다.

연구는 병영 Lv.2에서 해금되며 즉시 적용됩니다.

| 연구 | 단계당 효과 | 첫 단계 금 / 식량 | 최대 단계 |
| --- | --- | --- | --- |
| 강철 무기 | 병사 공격력 +12% | 80 / 50 | 3 |
| 강화 갑옷 | 병사의 전투 피해 8% 감소 | 65 / 65 | 3 |
| 보급 체계 | 이동 속도 +8%, 자원 생산 +6% | 60 / 80 | 3 |

두 번째 연구는 첫 단계 비용의 2배, 세 번째는 3배입니다. 같은 연구의 단계 효과는 합산됩니다. 정책·장군·전술 지원 등 서로 다른 계열의 배율은 곱해 적용합니다. 갑옷과 방어 진형은 폭풍 피해를 막지 않습니다.

## 건물 내부 탐험과 시설 운영

전장 상단의 **기지 관리 · 장군 (K)** 버튼을 열어 5×5 설계도에 들어갑니다. 빈 땅을 누르면 선택한 시설을 건설하고, **완공된 금광·농장·병영·방어탑을 누르면 내부 공간에 입장**합니다. 전략 시점에서 실제 3D 전장 옆의 아군 건물을 클릭해도 같은 내부 공간으로 들어갈 수 있습니다. 내부는 방마다 다른 설비·조명·작업대가 표현된 인터랙티브 3D풍 화면이며, 설비 확장과 작업을 버튼으로 실행합니다. 별도의 자유 이동형 3D 실내는 아닙니다.

| 건물 내부 | 설비 확장 | 즉시 실행 가능한 작업 |
| --- | --- | --- |
| 지하 금광 | 금광 단계 증가 → 금 생산 상승 | 식량 80으로 금 55 확보, 채굴 현황 확인 |
| 왕립 농장 | 농장 단계 증가 → 식량 생산 상승 | 금 80으로 식량 55 확보, 성장 정책 전환 |
| 왕립 병영 | 병영 단계 증가 → 병종·연구 해금 | 보병 3명 훈련 (대규모 전장에서는 25명), 무기 연구 |
| 성채 방어탑 | 최대 체력 +100 및 포탑 강화 | 금 45·식량 25로 본부 체력 +100 수리, 수비대 지정 |

내부에서 진행하는 설비 확장은 기존 건설 시스템과 **동일한 자원·단계 제한**을 적용하며, 확장 후 기지 설계도에는 같은 종류의 시설이 한 동 추가됩니다. 작업은 전투의 실제 자원·병력·연구·방어 수치에 반영되며, **자동 저장**되고 기존 전투 세이브와 호환됩니다. 기지 관리 화면이 열려 있는 동안 전투 시뮬레이션이 정지합니다. 내부에서는 **Esc** 또는 뒤로 버튼으로 설계도로 돌아오고, 다시 Esc를 누르면 전장으로 복귀합니다.

## 전술 스킬과 기지 배치 개선

- **장군 전술 스킬:** 레온(전장의 함성: 공격), 소라(질풍 진군: 이동), 미라(철벽 방진: 피해 감소), 한(긴급 보급: 생산)이 고유 스킬을 발동합니다. 전투 장군은 부대 배치가 필요하며, 한 총감은 배치 없이 사용할 수 있습니다.
- **효과 시간과 재사용 대기:** 전투 스킬은 10초 지속·40초 재사용 대기, 긴급 보급은 12초 지속·45초 재사용 대기입니다. 게임이 일시정지되면 타이머도 정지하고 저장 후 이어하기에도 상태가 유지됩니다.
- **기지 건물 이전:** 기지 건설 화면의 '배치 변경'에서 옮길 시설과 빈 부지를 차례로 선택하면 무료로 재배치할 수 있습니다. 건물 레벨, 생산량, 자원은 변하지 않으며 3D 영지 배치에 반영됩니다.

## 원정 계약과 전술 지원

### 원정 계약

`원정` 탭에서 진행도를 확인하고 완료한 계약의 보상을 받습니다. 계약은 병렬로 진행되며 **한 원정에서 한 번만** 보상을 받을 수 있습니다. 화면을 클릭한 횟수가 아니라 현재 시설·병력·거점과 누적 통계를 확인합니다.

| 계약 | 완료 조건 | 일반 원정 보상: 금 / 식량 |
| --- | --- | --- |
| 자립하는 영지 | 금광과 농장 모두 Lv.2 | 55 / 40 |
| 새로운 선봉대 | 병력 4명 훈련; 대규모전은 25명 | 55 / 45 |
| 첫 번째 깃발 | 거점 1개 보유 | 75 / 55 |
| 기술의 힘 | 기술 연구 1회 완료 | 65 / 55 |
| 함께 싸우는 군단 | 생존 아군에 3종 이상 병종 편성 | 85 / 65 |
| 지휘관의 깃발 | 장군 1명 모집 | 80 / 65 |
| 이어지는 보급로 | 거점 3개 동시 보유 | 120 / 100 |
| 흔들리지 않는 본부 | 본부 방어 Lv.3 | 100 / 75 |
| 새로운 패권 | 적 왕국 1개가 함락될 때까지 생존 | 180 / 140 |

대규모전에서는 보상이 표의 3배입니다. 조건이 충족되어도 수령 버튼을 눌러야 보상이 지급됩니다. 이미 수령한 계약은 저장 후 이어하기에서도 다시 받을 수 없습니다.

### 선택 부대 지원

| 지원 | 효과 | 일반 원정 비용: 금 / 식량 | 재사용 시간 |
| --- | --- | --- | --- |
| 야전 치료 | 생존 병력의 체력을 최대 체력의 35%만큼 즉시 회복 | 55 / 45 | 45초 |
| 강행군 | 14초 동안 이동 속도 +40% | 45 / 35 | 50초 |
| 방어 진형 | 14초 동안 받는 전투 피해 30% 감소 | 65 / 45 | 60초 |

먼저 주력군·기동대·수비대 중 지원할 그룹을 선택하세요. 빈 부대나 자원이 부족한 요청에는 비용이 들지 않으며, 야전 치료는 모든 병사의 체력이 가득 찼을 때 사용할 수 없습니다. 재사용 시간은 **지원 종류별로 공유**하며 게임 시간으로 흐릅니다. 일시정지 중에는 남은 시간이 줄지 않습니다. 대규모전의 지원 비용은 표의 3배입니다.

## 거점·지형·폭풍·난이도

거점 주변에 한 세력의 병력만 있으면 점령이 진행됩니다. 여러 세력이 함께 있으면 점령이 중단되고 누적 점령도가 줄어듭니다. 점령 속도 보너스는 5명에서 상한에 도달합니다. 직접 조작 캐릭터도 적 병력의 방해가 없는 거점을 확보할 수 있습니다.

벙커·격납고·정제소·레이더·장벽·참호·결정 광물·숲 등의 시설은 고정 시드로 배치됩니다. 일부 시설은 실제 이동을 막고 주변 병력에 엄폐 효과를 제공합니다. 이동은 장애물 주변의 짧은 우회 후보를 사용합니다. 장애물 파괴, 완전한 장거리 경로 탐색과 탄환 시야 차단은 구현 범위에 포함되지 않습니다.

### 폭풍

다음 시간부터 안전지대가 줄어듭니다. 모든 시간은 화면에 표시되는 **게임 시간**입니다.

| 전장 | 일반 원정: 보통·도전 | 일반 원정: 입문 | 대규모전: 보통·도전 | 대규모전: 입문 |
| --- | --- | --- | --- | --- |
| 강철 분지 | 2분 10초 | 3분 | 4분 30초 | 6분 |
| 황혼 변경 | 2분 56초 | 4분 3초 | 6분 5초 | 8분 6초 |
| 서리 대륙 | 3분 41초 | 5분 6초 | 7분 39초 | 10분 12초 |

안전지대 밖에서 본부는 기본 초당 3.5, 병사는 초당 1.8의 피해를 받습니다. 점령한 거점 하나당 본부의 폭풍 피해가 12% 감소하며 최대 60%까지 줄어듭니다. 확대 맵은 폭풍 시작과 축소 규모도 맵 크기에 맞춰 조정합니다.

### 난이도

| 난이도 | 아군 생산량 | AI 생산량 | AI 판단 간격 | AI 본부 공세의 기본 준비 시간 |
| --- | --- | --- | --- | --- |
| 입문 | 135% | 55% | 170%, 더 느림 | 260초 |
| 보통 | 100% | 100% | 100% | 105초 |
| 도전 | 100% | 120% | 80%, 더 빠름 | 없음 |

본부 공세의 준비 시간에는 맵별 1 / 1.35 / 1.7배 배율을 적용합니다. 준비 시간이 지나도 AI는 병력·영토 상황을 보고 공격을 결정합니다. 준비 중에도 경제·훈련·점령과 병력 간 전투는 계속됩니다. 입문에서는 AI가 병력에 가하는 전투 피해에도 완화 배율을 적용합니다.

## 조작

### 전략 시점

| 입력 | 동작 |
| --- | --- |
| WASD / 방향키 | 카메라 이동 |
| 마우스 드래그 | 카메라 회전 |
| Shift + 드래그 / 터치 드래그 | 카메라 이동 |
| 마우스 휠 / 화면의 +·− / 두 손가락 확대·축소 | 시점 확대·축소 |
| H | 내 본부로 시점 이동 |
| 1 / 2 / 3 / 4 | 보병 / 궁병 / 중장병 / 기병 1명 훈련 |
| 5 / 6 / 7 | 주력군 / 기동대 / 수비대 선택 |
| G | 지도에서 부대 이동 지점 지정 |
| B | 선택 부대의 본부 복귀 |
| M / 전체 지도 | 전체 작전 지도 열기 |
| K / 기지 관리 | 건설·장군 관리·완공 건물 내부 입장 |
| Esc / 일시정지 | 일시정지·재개 |
| 거점·적 본부 클릭 | 대상 상세 정보 |
| Shift + 클릭 / 우클릭 | 선택 대상에 전술 명령 |
| 미니맵 클릭 | 시점 이동; 위치 지정 모드에서는 선택 부대 명령 |

전체 작전 지도에서는 먼저 부대와 목적지를 고릅니다. **시점 이동**은 카메라만 옮기며 **부대 출전**이 실제 명령입니다. 지도에 포커스한 상태에서 방향키로 지점을 고를 수 있고, Shift를 함께 누르면 더 크게 이동합니다. 지도 확인 중에는 전투가 일시정지합니다.

### 직접 플레이

| 입력 | 동작 |
| --- | --- |
| V / 직접 플레이 버튼 | 직접 조작으로 전환 |
| WASD / 화면 이동 패드 | 캐릭터 이동 |
| F / 활 발사 | 사격 |
| E / 성벽 버튼 | 가까운 성벽 오르내리기 |
| T / 전략 지도 버튼 | 전략 시점으로 복귀 |

새 전투는 낙하산 강하로 시작합니다. 전략 시점과 직접 플레이를 오가며 같은 원정의 병력과 거점을 관리합니다.

상단 배속 버튼은 **0.5·0.65·0.85·1·1.5배**를 순환하며 기본값은 0.65배입니다. 다른 창으로 이동하면 전투가 일시정지합니다. 작은 화면에서는 관리 패널을 접을 수 있습니다.

## 저장과 설정

- 전투·전적·설정은 브라우저의 `localStorage`에 보관합니다. 계정 동기화나 서버 저장은 제공하지 않습니다.
- 게임 시간 15초마다 자동 저장합니다. 수동 저장과 메뉴 복귀 저장도 지원합니다.
- 현재 전투 저장 형식은 **v4**입니다. 유효한 기존 v1·v2·v3 저장은 강철 분지로 이전하고 새 계약·지원 상태를 초기화합니다. 저장 키는 이전 기록을 발견할 수 있도록 그대로 유지합니다.
- 맵과 좌표, 병력 상한, 거점 참조, 건설 부지, 장군 배속, 계약 중복 수령, 지원 시간과 승패 상태를 검증합니다. 복원할 수 없는 현재 상태로 기존 정상 저장을 덮어쓰지 않습니다.
- 새 원정 시작 전 기존 진행을 덮어쓸 수 있다는 안내를 표시합니다. 다른 맵을 선택한 뒤 이어하기를 눌러도 저장된 원정의 맵·난이도로 복귀합니다.
- 그래픽 품질·효과음·움직임 줄이기 설정을 제공합니다. 낮음 품질은 렌더 해상도와 효과를 줄입니다. 메뉴 3D 프리뷰는 별도의 가벼운 렌더 설정을 사용합니다.
- 패널의 FPS는 실제 렌더링 횟수로 계산합니다. 일정 프레임 속도를 보장하는 값은 아닙니다.

### 원정 기록실

메뉴 아래 **원정 기록 · 업적**에서 최근 20개 완료 전투의 전장·난이도·승패·전투 시간·처치·점령·훈련·연구·계약·전장 지원 횟수를 확인합니다. 진행 중인 전투는 기록하지 않습니다. 20개를 넘은 오래된 개별 기록이 사라져도 누적 전적과 최초 업적 획득 시각은 남습니다.

업적은 첫 전투·첫 승리·세 전장 승리·군단전 승리·한 원정의 모든 계약 수령·10회 전투·전술 지원 20회·거점 점령 50회의 8종입니다. 전투 능력이나 자원을 바꾸지 않는 기록 배지이며, 기존 전적 키와 별도 저장합니다. 기록실의 날짜는 한국 표준시입니다.

## 클래식 서바이벌

메뉴 아래의 클래식 서바이벌은 기존 Phaser 게임입니다. WASD/방향키 이동, 자동 공격, 경험치 수집, 레벨업 3지선다, 무기·패시브 성장, 구간·미니보스·최종 보스를 지원합니다. 현재는 원형 플레이스홀더 그래픽을 사용하는 별도 프로토타입입니다.

`src/sim/`, `src/scenes/`, `src/render/`, `data/`가 이 모드에 속합니다. 전략 원정의 맵·경제·저장을 공유하지 않습니다. `?seed=123`, `?speed=10`, `npm run balance`도 클래식 서바이벌에 적용됩니다.

```bash
npx playwright install --with-deps chromium --only-shell

node tools/frontiers-smoke.mjs
```

브라우저 스크립트는 각각 로컬 Vite 서버를 시작하고 종료합니다. 기본 회귀 검사는 데스크톱·390px 모바일·320px 소형 모바일·가로 화면을 다룹니다. Frontiers 검사는 세 맵의 일반·대규모 전쟁과 추가 모바일 사례를 다룹니다. 스크린샷, 서버 로그, `report.json`은 `browser-artifacts/`와 `browser-artifacts/frontiers/`에 기록합니다.

GitHub Actions의 **CI**, **Browser smoke**, **Frontiers browser smoke**에서 같은 검사를 실행합니다. 실행 페이지의 Artifacts에서 스크린샷과 보고서를 내려받을 수 있습니다. 브라우저 검사의 자원·부상·승리 상태 지정은 보고서에 명시합니다. 이는 실제 DOM·WebGL 동작 검사이며, 무개입 완주 기록이나 물리적인 휴대폰 GPU 측정을 뜻하지 않습니다. 현재 통과 여부와 테스트 수는 해당 커밋의 CI 결과를 확인하세요.
