# 서바이벌 픽셀 (가칭)

탑다운 자동 공격 서바이벌 게임입니다. WASD로 움직이면 무기가 알아서 공격하고, 레벨이 오를 때마다 셋 중 하나를 골라 강해집니다.

Phaser 3 + TypeScript + Vite로 만들며, 구조와 규칙은 [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)에 정리되어 있습니다.

## 시작하기

Node 22 이상이 필요합니다.

```bash
npm install
npm run dev        # http://localhost:5173 에서 실행
```

| 명령 | 하는 일 |
|---|---|
| `npm run dev` | 개발 서버 |
| `npm test` | sim과 데이터 테스트 |
| `npm run lint` / `npm run typecheck` | 코드 검사 |
| `npm run validate-data` | `data/*.json` 검증 |
| `npm run balance -- --runs 20` | 봇으로 20판을 돌려 결과를 CSV로 출력 |
| `npm run build` | 배포용 빌드 (`dist/`) |

개발할 때 유용한 주소 옵션: `?seed=123`은 같은 판을 재현하고, `?speed=10`은 10배속으로 돌립니다.

## 폴더

| 폴더 | 내용 | 규칙 |
|---|---|---|
| `data/` | 적, 무기, 패시브, 구간, 밸런스 JSON | 코드 없이 수정. 잘못된 값은 실행 시 화면과 CI에서 알려 줍니다 |
| `src/sim/` | 게임 규칙 전부 | Phaser, `Math.random`, `Date` 사용 금지 (린트가 막습니다) |
| `src/render/`, `src/scenes/` | 화면, UI, 연출 | sim 상태를 읽기만 하고 바꾸지 않습니다 |
| `src/data/` | JSON 스키마와 로더 | `schema.ts`가 JSON 형식의 유일한 정의 |
| `public/assets/` | 스프라이트, 타일, UI, 오디오 | |
| `tools/` | 데이터 검증, 밸런스 시뮬레이션 | |
| `tests/` | 자동 테스트 | |

## 지금 되는 것과 남은 것

되는 것: 이동, 구간별 스폰, 자동 공격(무기 5종: 투사체형 3, 회전형 1, 오라형 1), 넉백과 적끼리 밀어내기, 데미지 숫자와 처치 효과, 경험치와 레벨업 3지선다, 패시브 6종, 구간 전환과 미니보스, 마지막 보스, 결과 화면과 재시작. 그림은 전부 색칠한 원(플레이스홀더)입니다.

남은 것: 무기 3종 추가(광선, 부메랑 등 새 패턴), 적 행동(원거리, 무리), 보스 패턴, 스프라이트와 타일셋, 이펙트와 사운드, 밸런스, 배포 자동화.

## 3D 4인 경영 전쟁

메뉴에서 **3D 4인 경영 전쟁 (AI)**을 선택합니다. 플레이어 1명과 AI 세 세력이 각각 영지를 운영합니다. 금광과 농장을 강화해 금과 식량을 생산하고, 병영을 강화해 병사의 공격력을 높이세요. 본부 방어를 강화하면 본부 체력이 늘어납니다. 자원을 써 병사를 훈련하고 방어 또는 적 영지 공격을 지시할 수 있습니다. 병사는 가까운 적을 자동 공격합니다. 본부를 잃으면 해당 세력은 탈락하며 마지막으로 남으면 승리합니다.

90초 후 파란 안전지대가 줄어들며 밖에 있는 본부와 병사는 피해를 받습니다. 화면 드래그로 시점을 회전하고 휠로 확대·축소할 수 있습니다. 브라우저 WebGL이 필요합니다. 이 모드는 온라인 멀티플레이가 아닌 AI 대전입니다.


### 전략 모드 확장 (3D 경영 전쟁 v2)

3D 경영 전쟁은 기존 서바이벌 모드와 별개로 실행되며, 온라인 대전이 아닌 **1명 대 AI 3개 세력**입니다.

- **경영:** 농장과 금광을 강화해 금·식량을 지속 생산하고, 병영으로 병종을 해금하며 본부를 강화해 체력과 방어탑 화력을 높입니다.
- **병력:** 보병(기본), 궁병(병영 2레벨), 중장병(병영 3레벨)을 자원을 소비해 훈련합니다. 세력당 최대 18명입니다.
- **거점:** 북부 광산·동부 시장·남부 곡창·서부 항구·중앙 요새의 5개 거점에 병사를 보내 점령할 수 있습니다. 각 점령 거점은 금 +1.15/초, 식량 +0.9/초를 추가 생산합니다. 적과 아군이 동시에 있으면 점령이 진행되지 않습니다.
- **전쟁:** 적 본부를 공격하거나 기지를 방어하도록 지시할 수 있습니다. AI는 경제 투자, 병력 생산, 거점 점령, 적 본부 공략을 자율적으로 선택합니다.
- **전장:** 90초 이후 안전지대가 점차 축소되며 영역 밖 본부·병사는 지속 피해를 입습니다. 본부를 잃으면 탈락, 마지막 생존 세력은 승리합니다.
- **조작:** 마우스 드래그로 카메라 회전, 휠로 확대·축소, 상단 버튼으로 일시정지·1/2/4배속 조절. 좌측 패널에서 생산시설 강화, 병력 훈련과 명령을 실행합니다.

전략 엔진은 Three.js 렌더링과 독립적인 `src/battle/war.ts`에 있으며 전략 규칙 테스트는 `tests/battle/strategy.test.ts`에 있습니다. 직접 실행하려면 `npm ci && npm run dev` 후 제목 화면에서 **3D 4인 경영 전쟁 (AI)**을 선택합니다.


### 3D 그래픽 업그레이드

`src/battle/graphics.ts`에서 Three.js로 생성하는 스타일라이즈드 3D 모델과 환경을 관리합니다. 성벽·성문·망루·성채·기와 지붕·깃발, 건물별 개별 모델(농장·광산·병영), 보병·궁병·중장병의 장비, 거점 수정과 점령 표시, 지형 색상 변화·도로·나무·바위·물·구름을 포함합니다. 캐릭터 걷기, 거점 부유 애니메이션, 투사체, 안전지대 폭풍 연출을 추가했습니다.

고품질 모드는 ACES 톤 매핑, sRGB 출력, 소프트 실시간 그림자와 최대 2배 픽셀 비율을 사용합니다. **그래픽 높음/보통** 버튼으로 그림자와 렌더 해상도를 조절합니다. 모바일에서는 기본적으로 보통 모드가 활성화됩니다. 외부 3D 에셋을 내려받지 않으며 WebGL을 지원하는 브라우저가 필요합니다.


### 확장 전장 및 추가 기능

- 전장 너비 370 게임 단위(이전 142 단위 렌더 영역 대비 약 2.6배), 실질 면적 약 6.8배. 왕국은 사방 외곽으로 배치됩니다.
- 거점 9곳으로 확장. 초기 폭풍 반경 179이며 130초 뒤부터 점진적으로 축소됩니다.
- 화면 이동: WASD/방향키, Shift+드래그로 이동, 일반 드래그로 회전, 휠로 확대. **내 영지** 버튼으로 즉시 복귀.
- 오른쪽 하단 미니맵에서 4개 세력·9개 거점·병력과 안전지대를 확인하고 클릭으로 시점을 옮길 수 있습니다.
- 본부 수리(금 45·식량 25, 체력 100 회복), 병종별 3명 일괄 훈련 버튼을 추가했습니다.
- 맵 확대에 맞춰 도로·나무·바위·카메라·실시간 그림자 영역을 조정했습니다.

### 전술·경영·저장 확장

- 왕국 정책: 균형(기본), 성장(금·식량 생산 +25%), 전시(공격력 +18%, 자원 생산 -12%). 경제 정책은 버튼으로 언제든 변경할 수 있습니다.
- 본부 수비대: 0/2/4/6명을 기지에 남겨 방어하도록 지정합니다. AI 역시 병력 현황에 따라 수비대를 운영합니다.
- 거점 생산 전문화: 각 거점의 금/식량 보너스가 서로 달라져 목표 선택의 전략적 가치가 커집니다. 마우스를 거점 버튼에 올리면 보너스를 확인할 수 있습니다.
- 이벤트 기록: 최근 8개의 점령/본부 함락 사건을 기록하고, 최근 5개를 화면에 표시합니다.
- 키보드: ESC 일시정지, 숫자 1/2/3으로 보병/궁병/중장병 훈련, Shift+드래그로 두 축을 따라 카메라 이동.
- 로컬 저장: 전투 화면에서 **저장**, **이어하기**, **새 전투**를 사용할 수 있습니다. JSON 스냅샷을 버전·범위 검증한 후 복구하며, 잘못된 저장 데이터는 안전하게 무시합니다. 브라우저 저장 공간이 제한된 경우 실패 메시지가 표시됩니다.
- WebGL을 사용할 수 없는 환경은 안내 화면에서 메뉴로 돌아갈 수 있습니다.
- 단위별 사망·생성을 반복해도 동적 병사 장비의 GPU 자원이 누적되지 않도록 공유 지오메트리와 머티리얼을 사용합니다.
