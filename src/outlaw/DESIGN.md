# OUTLAW CITY — 디자인 & 게임 설계 지침

"플레이 10초 안에 웃음이 나오고, 10분 뒤엔 '한 판만 더'가 되는 도시." 모든 모듈은 이 문서를 기준으로 **디자인 품질과 게임의 손맛**을 맞춥니다.

## 1. 아트 디렉션: 네온 누아르 · 황혼의 도시
- **시간대**: 시작은 황혼(16:36). 해 질 녘의 주황~보라 하늘, 길게 늘어진 그림자, 켜지기 시작하는 가로등/네온/창문 불빛이 이 게임의 첫인상입니다. 낮은 선명하고 따뜻하게, 밤은 청록·마젠타 네온이 젖은 아스팔트에 번지는 느낌(바닥에 약한 반사 하이라이트).
- **팔레트**: 배경 도시는 채도를 낮춘 청회색/베이지/벽돌색, 포인트는 강한 색 — 마젠타 `#ff3d81`, 시안 `#3df2ff`, 미션 노랑 `#ffd23f`, 위험 빨강 `#ff4545`, 경찰 파랑 `#3b82ff`, 현금 초록 `#5dff8f`. 한 화면에 포인트 색은 2~3개만 동시에.
- **형태 언어**: 로우폴리지만 매끈한 면, 각진 실루엣, 과한 디테일 대신 *조명과 색*으로 분위기. 건물은 지구별 정체성이 뚜렷하게(다운타운 유리 타워 군, 주거지 벽돌/주택, 공업지구 컨테이너·굴뚝·철골).
- **카메라 연출**: 속도감(FOV 확장·약한 흔들림), 폭발 시 짧은 슬로모션 느낌의 카메라 킥, 충돌 시 화면 가장자리 비네트, 사망 시 흑백 + 슬로우.

## 2. UI/HUD 디자인
- 한국어 UI. 글꼴은 기존 Pretendard 계열을 쓰되 제목/숫자는 **굵은 이탤릭 대문자 + 넓은 자간 + 검은 외곽선**으로 GTA 같은 "거친 포스터" 느낌. 패널은 최소화(반투명 어두운 유리), 중요한 정보만 크게.
- 현금은 우상단 초록 숫자(변화 시 튀어 오르며 +$ 표시), 수배는 별 5개(획득 시 번쩍·수색 중 깜빡), 미니맵은 좌하단 둥근 레이더(방향 회전, 경찰 점 깜빡), 무기는 우하단.
- **무기 휠**: Q 를 누르고 있으면 방사형 무기 선택(슬로우 모션 효과) — 총 7종을 빠르게 고르는 손맛.
- 메뉴: 타이틀 화면은 정지 이미지가 아니라 **게임 도시를 느리게 공중 선회하는 카메라**(황혼) 위에 로고 OUTLAW CITY 와 메뉴. 일시정지·상점·지도·브리핑 모달도 같은 시각 언어(마젠타 포인트 라인, 두꺼운 제목, 큼직한 버튼).
- 큰 연출 문구: `MISSION PASSED +$…`, `WASTED`, `BUSTED`, `WANTED`, `NEW RECORD` 등은 화면 중앙에 크게 등장 후 사라짐(진입 모션·여운).
- 모바일/터치도 1급 시민: 터치 UI 는 엄지 영역에 맞고 시야를 가리지 않게.

## 3. 게임의 손맛(Game Feel) — 반드시 지킬 것
- **총**: 무기마다 확실히 다른 반동·소리·섬광·탄도. 명중 시 히트마커(헤드샷은 다른 모양/소리), 처치 시 짧은 확인음. 맞은 적은 움찔하고 밀려남. 근접(펀치)도 리듬과 타격감.
- **차**: 가속·핸드브레이크 드리프트가 재미있어야 함(아케이드 우선, 현실성은 2순위). 점프대/경사로 비행, 충돌 시 파편·경적·사람들의 비명. 차마다 성격(스포츠카 민첩, 트럭 묵직, 전차 무적).
- **카오스는 보상**: 도시는 건드릴수록 반응합니다 — 시민은 비명 지르며 흩어지고 운전자는 경적과 패닉, 경찰은 단계적으로 점점 더 거칠게 쫓아옵니다. 하지만 잘 도망치면 짜릿한 해방감(별이 사라지는 순간의 소리·연출).
- **스타일 점수**: 아슬아슬한 차 사이 통과(near miss), 공중 체공 시간, 드리프트 연속, 헤드샷 연속 처치, 점프 스턴트 등이 "STYLE" 보너스(현금)와 콤보 배율로 팝업(연출 큼직하게). 위험을 감수한 플레이가 돈이 되게.
- **진행(Progression)**: 현금 → 총기/방탄복 구입 → 미션 해금 → 더 큰 보상. 안전가옥 저장·체력 회복, 숨은 꾸러미 30개 수집, 스턴트 점프 12곳, 사이드 활동(택시 손님 태우기, 무장 현금수송차 털기, 현상금 사냥, 렘페이지)로 도시를 파헤칠 이유를 계속 제공.
- **튜토리얼 없이 배우기**: 첫 3분 안에 이동·사격·차 훔치기·수배·도망을 자연스럽게 겪도록 상황 힌트(하단 프롬프트와 토스트)만 짧게. 막히지 않게(차를 잃어도 근처에 늘 차가 있음).
- **공정함**: 즉사/억울한 죽음 최소화, 체포·사망 페널티는 아프지만 가볍게(돈 일부 + 무기 일부), 재시도 즉시.
- **여운**: 라디오(3개 방송)와 도시 앰비언스, 시간이 흐르며 변하는 하늘, 미션 대사의 개성.

## 4. 품질 체크리스트(모듈 작성자용)
- 화면에 보이는 것은 "예쁘게 보이는지"를 스크린샷으로 확인합니다(가능한 모듈은 반드시).
- 숫자를 정할 땐 *재미*를 기준으로 튜닝합니다(지루하면 줄이고 답답하면 풀기).
- 모든 상태 변화에는 시각·청각 피드백이 있어야 합니다.
